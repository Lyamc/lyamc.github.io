Methodology

What is timed

A single new process: start, do the work, print, exit. The clock is Python time.perf_counter() around subprocess.run (wait-for-exit). The reported number is the median of 5 samples, except Octave / Groovy / Raku / GPU (3) and Forth sieve (1).

Hello and Fibonacci(42) are a few dozen operations. They measure launch cost (OS spawn, CRT, VM/JIT init, print). The sieve to 1,000,000 and the sort of 1,000,000 LCG integers are the two programs that actually move memory.

LCG: seed = seed * 1664525 + 1013904223, then often & 0x7fffffff. Sorted first/last must be 3842 / 2147480074. Sieve count must be 78498.

Fairness

Not every row is the same problem. Compiled languages usually use a byte sieve and many use LSD radix for sort. Interpreters use whatever the language provides (list.sort, table.sort). Bend 2 uses a tree runtime; its sort is bitonic over 2^18 leaves rather than 1e6 list.sort. o3-monkey ran reduced n. GPU times include vkCreateDevice / wgpu instance setup.

Jai

Sources live in examples/jai/ (hello, Fibonacci, byte sieve, LSD radix sort). The Thekla / Jonathan Blow compiler is still an invite-only closed beta and was not present on this machine (home, PATH, Windows C:\, Downloads, tools/). There is no public Linux/Windows download to fetch. If you have the beta zip, unpack it so jai is on PATH or at tools/jai/bin/jai, then run python scripts/bench_jai.py.

Lean 4

Added as examples/lean/. Built with lake build (Lean 4.33.1, C backend via leanc/clang -O3). Sieve uses ByteArray. Sort is LSD radix over packed little-endian UInt32s in a ByteArray (the unboxed array type; Array UInt32 boxes). Timed on Linux NixOS, same i9-13900K as the Windows rows. Process spawn is cheaper on Linux: local clang -O2 C hello is 0.8 ms here versus 3.7 ms on Windows. C sieve 4.3 ms / sort 12.6 ms on this box versus Windows clang 4.8 / 9.6. Lean numbers are therefore slightly optimistic on hello and in the same band on the work.

python scripts/build_website.py --build
